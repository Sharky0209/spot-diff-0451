Spot the Difference — three original hand-drawn scenes (Garden Cottage, Lighthouse Bay, Winter Market), 24 differences in all, 90 seconds a level, hints, combos and a time bonus. Click a difference on either picture: a green ring and a check mark it, the counter shows how many are left. Built by an AI agent for make.fun's “Make the best spot the difference game” bounty, $50 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Play it locally with `node serve.ts`, then open http://localhost:8080. No build step, no network: the game is plain static files under `game/`, all art drawn in code.
